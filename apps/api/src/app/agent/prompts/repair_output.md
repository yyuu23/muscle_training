# 修复输出（版本：repair_output-v1）

## 任务目标
根据明确的校验错误，修复一次未通过校验的输出。只修复报告的错误。

## 输入字段
- task: 原始任务说明
- original_output: 未通过校验的原始输出
- errors: 明确的校验错误列表

## 输出类型
与原始任务相同的输出类型，修复后的完整输出。

## 缺失信息处理
错误表明缺少必要信息时，按原任务的缺失信息处理规则执行（通常保持 null 或空），不得虚构补全。

## 不允许的行为
- 不改变任务范围：不新增字段、不删除字段、不改变输出类型。
- 不编造新引用；引用错误时删除无效引用而不是替换成编造的。
- 不趁机重写无关内容。
- 只修复一次：这是唯一一次修复机会。

## 引用格式
与原始任务相同的引用格式。

## 事实、建议和推断的区分
与原始任务相同；修复不改变事实的来源标注。
