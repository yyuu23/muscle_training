# 隐私与数据保留

对应 plan.md §9.5 / §11.4。

## 保留默认值

| 数据 | 默认策略 | 实现 |
|---|---|---|
| 档案、训练、测量、饮食、有效事实 | 保留至用户删除 | — |
| 计划版本 | 保留至用户删除 | — |
| 已发布字幕和资料 | 保留至来源删除 | — |
| 原视频、提取音轨 | **最长 7 天** | `retention_class=temporary_import` + 维护任务清理 |
| 导出文件 | **24 小时** | `retention_class=export` + 过期 |
| 普通对话原文 | **90 天** | 维护任务清理（`Message.created_at`） |
| 已确认长期事实 | 独立保留 | 不因对话过期失效 |
| 无敏感运行日志 | 30 天 | 运维策略 |
| 模型用量记录 | 12 个月 | `model_runs` |
| 系统备份 | 7 日 + 4 周 | `backup/retention.py` |

对话过期时已确认事实保留最小来源说明，不依赖已删除消息全文。

## 用户删除

`DELETE /account`（15 分钟内重新认证）→ 覆盖原始数据、候选记忆、摘要、向量、修订与附件 → 写入删除账本。旧备份按保留周期过期；**恢复旧备份后必须重放删除账本**（`deletion/ledger.reap_deletions_after_restore`）。

## 隔离

所有私有表带 `user_id`；跨用户访问统一 404。RLS 角色设计（migration_role/app_runtime/job_dispatcher/backup_role）见 plan §9.3——**当前迁移尚未启用数据库层 RLS 策略**，隔离目前依赖应用层过滤，这是记录在案的差距（见 acceptance.md）。

## 模型调用数据的说明（必须如实表述）

百炼官方说明**调用数据不用于训练**，同时说明会**保留调用产生的数据**。因此应用隐私表述为："模型供应商不会用你的数据训练模型，但会按其政策保留调用记录"——**不能写成"调用后零留存"**。

## 日志纪律

普通日志不保存完整提示词与健康资料正文；`jobs.payload` 只存实体 ID 与必要配置。
